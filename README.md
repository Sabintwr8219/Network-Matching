# Network Matching

This repository contains two related roadway-network matching workflows.

- `New Version`: revised TxDOT–OSM network processing and matching workflow.
- `NCTCOG Version`: DFW adaptation that matches directional NCTCOG roadway attributes and daily volumes to OSM short links.

Each folder contains its own workflow README and pipeline runner. Input datasets, generated outputs, and diagnostic scripts are excluded from the repository.
